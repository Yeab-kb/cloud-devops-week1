# Week 1 Linux Hands-on Lab: Your First Project Workspace

## Tasks Completed & Commands Used:
1. Create directory: mkdir -p ~/cloud-devops/week1
2. Create notes file: touch notes.txt
3. Add text to file: echo "This is my Week 1 DevOps lab notes." > notes.txt
4. Create scripts directory: mkdir scripts
5. Move notes file: mv notes.txt scripts/
6. Search for notes file: find ~/cloud-devops/week1 -name "notes.txt"
7. Identify running process PID: ps aux
